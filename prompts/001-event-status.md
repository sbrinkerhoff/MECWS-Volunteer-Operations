# Summary

The MECWS system needs to support the following event statuses:

- Projected
- Confirmed
- Completed
- Cancelled

# Details

## Projected

- The event is planned but not yet confirmed.  The team might want to stub out future events but not announce them yet.
- Volunteers cannot sign up for the event, or see it on the public calendar.

## Confirmed

- The event is confirmed.
- Volunteers can sign up for the event.

## Completed

- The event is completed.
- Volunteers cannot sign up for the event.

## Cancelled

- The event is cancelled.
- Volunteers cannot sign up for the event.
